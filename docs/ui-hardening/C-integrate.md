# C. 통합·검증 (opus)

가지 `ui/integ`, 워크트리 `.claude/worktrees/ui-integ`, 포트 8809. 먼저 `README.md`.
B 묶음 9개가 끝난 뒤에 한다. 이 단계만 공통 파일을 포함해 **모든 화면 파일을 고칠 수 있다**. 본 폴더와 `main`은 여전히 건드리지 않고 push도 하지 않는다.

## 할 일

1. **합치기**: `ui/p1-shell` … `ui/p9-quickjump`를 차례로 `git merge --no-ff`. 파일 소유가 안 겹치게 나눴으니 충돌이 없어야 한다. 충돌이 나면 소유 표를 어긴 쪽을 찾아 소유 묶음의 변경을 살린다. 합치기 전에 `git log ui/integ..<가지> --stat`으로 소유 밖 파일을 건드렸는지 본다.
2. **공통 요청 처리**: 오케스트레이터가 넘긴 `공통 요청` 목록(묶음 보고서에서 모은 것)을 `ui.js`·`api.js`·`style.css`·mock 공통 파일에서 처리하고, 요청한 화면이 그걸 쓰게 한다. 과한 요청은 하지 않고 까닭을 적는다.
3. **전 화면 확인**: `check.sh 8809`를 1440 밝은·어두운, `W=390 H=1100`, `W=1024 H=900`, 벽면으로. 콘솔 오류 0. 스크린샷을 **전부 눈으로** 본다. 볼 것:
   - 글자 꺾임·잘림·겹침, 어두운 테마에서 안 보이는 글·테두리
   - 같은 구실인데 화면마다 다른 모양(빈 상태·오류 상자·거르기 칩·토스트)
   - 화면 글이 길어진 곳(안내 문장이 늘었으면 줄이거나 ⓘ로), 같은 뜻에 다른 말
4. **묶음 사이를 넘는 흐름**(`eval`로):
   - 관제 → `✦ 원인` 서랍 → 타임머신 링크 → A·B 구간이 주소에 → 뒤로 가기
   - 빠른 이동으로 서버 → 프로세스 탭 → 종료 보고서 → 실행 타임머신
   - `SEARCH='?fail=/hosts'`: 위 막대 `갱신 끊김`, 시간 막대 `갱신 끊김`, 관제·서버 목록의 오류 상자, 다시 시도
   - 알림 일괄 확인 뒤 종 숫자와 탭 제목의 수가 같이 줄어드는지
   - Tab만으로 관제 → 서버 목록 줄 → 서버 상세까지 가는지, 포커스 윤곽선이 보이는지
5. **고치기**: 3·4에서 나온 문제를 고친다. 묶음이 `안 한 것`으로 남긴 항목 중 품이 작은 것은 한다.
6. `go build ./... && go vet ./internal/manager/... && go test ./internal/manager/...`.
7. README(저장소 뿌리)의 화면 설명에 이번에 바뀐 것을 5줄 안으로 더한다(빠른 이동, 갱신 끊김 표시, 알림 일괄 확인, 좁은 화면).

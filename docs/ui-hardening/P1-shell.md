# P1. 위 막대·트리 (sonnet)

가지 `ui/p1-shell`, 워크트리 `.claude/worktrees/ui-p1`, 포트 8811. 먼저 `README.md`, 그다음 `A-foundation.md`의 계약 표.
소유: `index.html`, `app.js`, `tree.js`, `grouporder.js`, `style.css`(#top·#menu·#tree·#layout 규칙만), `css/shell.css`(새 규칙은 여기).

## 할 일

1. **좁은 화면 위 막대**(지금 390px에서 메뉴 글자가 한 자씩 세로로 꺾이고 테마·사용자·시계가 밀려 나간다)
   - 로고·메뉴 글자는 꺾이지 않는다(`white-space:nowrap`). 900px 이하에서 메뉴는 한 줄 가로 스크롤(스크롤 막대 숨김, 켜진 메뉴가 보이게 `scrollIntoView`).
   - 600px 이하: 감사 기록·사용자·로그아웃은 `⋯` 단추의 작은 메뉴 안으로, 시계는 숫자 없이 상태 점만. 종·테마·찾기(`#qj-open`)·`#stale`은 남긴다.
   - 390px에서 위 막대가 한 줄 44px 안에 다 들어오고 가로 스크롤이 생기지 않아야 한다.
2. **트리 접기**: 위 막대 맨 왼쪽에 트리 여닫기 단추(`aria-expanded`, `aria-controls="tree"`). 상태는 `localStorage` `eum.tree.hidden`.
   - 900px 이하에서는 기본이 닫힘이고, 열면 본문 위에 덮이는 서랍으로 뜬다(바깥 누르기·Esc·항목 고르기로 닫힘). 지금은 900px 이하에서 트리가 아예 사라져 갈 길이 없다.
   - `body[data-page="edit"]`에서 숨기는 기존 규칙은 유지.
3. **트리 찾기**: 트리 맨 위 입력 칸(`aria-label="서버·플로우 찾기"`). 이름 부분 일치로 잎을 거르고, 맞는 잎의 묶음은 펼쳐 보인다. 비우면 원래 접힘 상태로 돌아간다. 옆에 `이상만` 켜고 끄기(정상·성공이 아닌 잎만). 5초 갱신에도 입력 값·포커스가 유지돼야 한다.
4. **트리 키보드**(`tree.js:153-166, 205`): 노드를 실제 포커스 대상으로. `role=tree`/`treeitem`, 묶음에 `aria-expanded`, ↑↓ 이동, →← 펼침·접힘, Enter 이동. 지금 화면의 노드에 `aria-current`.
5. **연결 점**(`app.js:77`): 색만 바뀐다. `title`·`aria-label`에 `연결됨`/`응답 실패`.
6. **1024px**: 트리가 열려 있어도 본문이 760px 아래로 내려가면 트리를 덮는 방식으로 바꾸는 분기점을 정한다(2의 서랍 방식 재사용). 값은 `css/shell.css` 한 곳에.

## 하지 않는 것

화면 본문(`#page` 안), 빠른 이동 내용(P9), 토스트·모달(A). `app.js`의 A가 넣은 부분(끊김 표시·제목·오류 화면)은 그대로 둔다.

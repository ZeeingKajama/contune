## 할 일 (하나 끝날 때마다 커밋)

1. **토큰 치환**: A가 정의한 `--r-*`·`--z-*`·`--fs-*`로 바꾼다.
   - z-index 13단계(1, 2, 3, 5, 6, 20, 30, 40, 41, 45, 50, 60, 100) → 토큰. 화면 안 쌓임(1~6)은 그대로 둬도 된다.
   - border-radius: 4·6·8px만 토큰으로. 알약 모양(9px 이상)은 그대로.
   - font-size: 11·12·13px만 토큰으로. 9px·11.5px·12.5px·17px 같은 예외는 가장 가까운 단계로 옮기되 스크린샷 차이를 확인.
2. **분기점**: `@media` 폭 11가지(900·1100·1180·1200·1300·700·640·600·480·380·240) → 600 / 900 / 1200 셋으로 모은다. CSS 변수는 미디어 쿼리에 못 쓰니 `style.css` 머리에 주석으로 기준을 적고 값을 맞춘다. 240·380처럼 위젯 폭(컨테이너 쿼리)인 것은 그대로.
3. **카드**: 같은 규칙 9벌(`.rbox` `.bt-card` `.bz-card` `.dcard` `.dpanel` `.srv-cell` `.tm-card` `.ex-card` `.rn-card`) → `style.css`에 `.card` 하나(배경·테두리·둥글기 8px·안쪽 여백), 화면 클래스는 차이만 남긴다. 둥글기가 6px이던 카드는 8px로 맞춘다(뜻한 차이).
4. **구간 단추**: 4벌(`.bt-seg` `.ed-seg` `.de-seg` `.trseg`) → `.seg` 하나. 켜진 색은 `.trseg` 방식(강조색 바탕 + `--on-accent`)으로 통일(배치판만 10% 섞음이던 것이 바뀐다: 뜻한 차이).
5. **흐린 글자·경로 줄**: `.dim` 5벌 + `.bt-dim` → `style.css` 하나. 경로 줄 3벌(`.bt-crumb` `.tm-crumb` `.ex-crumb`) → `.crumb` 하나, 12px.
6. **JS 도우미 사본**: `p2` 7벌, `q=encodeURIComponent` 6벌, `keepQuery` 5벌, `fmtBytes` 2벌, `parseDur` 2벌, 남은 `errText`·날짜 사본 → `ui.js`로 모으고 화면은 import. 동작이 미묘하게 다른 사본은 합치지 말고 주석으로 까닭을 남긴다.
7. **CSS 파일 수**: `index.html`이 20개를 따로 부른다. 묶지는 않는다(빌드 도구가 없다). 대신 안 쓰는 규칙을 찾아 지운다(클래스 이름을 JS·HTML에서 grep해 0건인 것만, mock·문자열 조립으로 만드는 이름 주의).
